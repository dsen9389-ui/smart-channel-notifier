Smart Channel Notifier Bot

Overview
Monitor external websites and push instant alerts to your Telegram channel seamlessly.

Features
- Scrape target web pages reliably
- Format alerts using markdown templates
- Push updates to channels automatically

Local Setup
1. Clone the repository
2. Install dependencies: pip install -r requirements.txt
3. Copy .env.example to .env and set your BOT_TOKEN
4. Run the bot: python main.py

Deployment
Deploy easily on Render or Koyeb using a Python background worker service.
